LOFT DESIGN · RAPPORT DÉVELOPPEUR · VERSION FINALE

Structure finale du devis, du contrat et de l’offre technique

Cette version remplace la logique précédente du grand NB global. Les éléments non inclus reviennent dans la fiche de chaque prestation. Le NB global est réservé aux prestations d’accompagnement chantier.

2. Une fiche complète pour chaque prestation sélectionnée

Chaque service sélectionné doit être affiché avec la même structure, dans le même ordre.

Conception 3D intérieure immersive
900 DA / m² · Intérieur
Description détaillée

Description complète de la prestation extraite du catalogue Admin.

Ce qui est inclus
  • Éléments inclus propres à cette prestation.
  • Livrables, corrections, études ou rendus prévus dans le service.
  • Tout élément réellement couvert par la prestation sélectionnée.
Non inclus dans cette prestation
  • Éléments explicitement exclus de cette prestation.
  • Prestations techniques ou d’exécution qui ne font pas partie de son périmètre.
Important : utiliser le libellé « Non inclus dans cette prestation » et non « Non inclus » tout court. Un élément exclu d’un service peut être couvert par un autre service sélectionné dans le même devis.

3. Source des contenus : catalogue Admin

Le développeur ne doit pas écrire les textes techniques directement dans le composant du devis.

technical_description

Description détaillée affichée dans la fiche du service.

included_items[]

Liste « Ce qui est inclus ».

excluded_items[]

Liste « Non inclus dans cette prestation », affichée en rouge.

loft_obligations[] / client_obligations[]

Utilisées pour personnaliser les obligations du contrat.

Ne plus fusionner tous les excluded_items dans un grand NB global. Les exclusions restent attachées à leur prestation respective.

4. Règle de cohérence entre prestations

R1 — Une exclusion affichée sous un service décrit uniquement la limite de ce service.
R2 — Si la même capacité est couverte par une autre prestation sélectionnée, ne pas la présenter comme une exclusion générale du contrat.
R3 — Le contrat doit montrer clairement ce que LOFT DESIGN réalise avant de montrer les limites de chaque prestation.
R4 — Les listes « inclus » et « non inclus » doivent rester courtes, ciblées et spécifiques au service.

6. Comportement dynamique du NB accompagnement

Aucune formule sélectionnée — afficher les 3 prestations dans le NB.
Une formule sélectionnée — elle devient une prestation normale du devis et du contrat avec Description + Inclus + Non inclus. Elle disparaît du NB. Le NB affiche seulement les formules restantes.
Deux formules sélectionnées — le NB affiche uniquement la formule restante.
Les 3 sélectionnées — ne pas afficher le bloc NB accompagnement.
Le comportement doit être identique dans le frontend dynamique. Dans le PDF, afficher uniquement les formules d’accompagnement non retenues, sans boutons.

7. Affichage Web vs PDF

Version web dynamique

  • Chaque prestation sélectionnée est cliquable.
  • Ouverture du descriptif détaillé.
  • Affichage Inclus.
  • Affichage Non inclus en rouge.
  • NB accompagnement avec Détails + Ajouter au devis.

Version PDF

  • Devis + Contrat uniquement.
  • Offre technique intégrée au contrat.
  • Description + Inclus + Non inclus pour chaque service.
  • Non inclus en rouge ou avec signalétique rouge lisible.
  • NB accompagnement sans boutons.

8. Obligations LOFT DESIGN — rester positives et concises

LOFT DESIGN s’engage à :

• réaliser les prestations sélectionnées conformément au devis et à l’offre technique ;
• fournir les études, plans, conceptions et livrables prévus dans le périmètre validé ;
• respecter les surfaces, quantités, corrections et modalités prévues pour les prestations retenues ;
• informer le client avant toute prestation ou coût supplémentaire hors périmètre ;
• assurer la qualité et la cohérence des livrables relevant directement de sa mission.

9. Obligations du client — version courte

Le Client s’engage à :

• fournir les informations, plans, mesures et documents nécessaires ;
• valider ou commenter les propositions dans des délais raisonnables ;
• signaler toute modification pouvant affecter le projet ou les études ;
• régler les montants dus selon le devis et les conditions convenues.

11. Tests d’acceptation P0

P0.1 — Chaque prestation sélectionnée affiche sa désignation complète, sa description, ses inclusions et ses exclusions.
P0.2 — Les exclusions propres au service apparaissent en rouge.
P0.3 — Aucun grand NB global ne regroupe les exclusions techniques de tous les services.
P0.4 — Le NB global contient uniquement les prestations d’accompagnement non sélectionnées.
P0.5 — Une formule ajoutée au devis disparaît immédiatement du NB et reçoit sa propre fiche technique.
P0.6 — Le PDF reproduit exactement la même logique, sans boutons interactifs.
P0.7 — Le devis web reste dynamique et chaque prestation peut être ouverte pour voir ses détails.

12. Instruction directe pour Gemini / Kimi / Codex

Applique cette structure finale dans le module devis/contrat LOFT DESIGN.

2. NB GLOBAL :
Le NB global est réservé aux prestations d’accompagnement chantier :
- Suivi de chantier
- Gestion & coordination de projet
- Assistance complète au maître d’ouvrage

- Ajouter au devis

Si une formule est ajoutée, elle devient une prestation normale du devis et du contrat avec Description + Inclus + Non inclus, et elle disparaît du NB.

Chaque prestation contient Description + Inclus + Non inclus.
Le NB accompagnement affiche seulement les formules non retenues et aucun bouton.
